# WP-03: Auth and workspace

## Goal
Add Better Auth to the Hono API and establish one workspace per registered user.

## Scope
- Better Auth email/password, organization workspace creation, session-derived workspace resolution.
- Auth routes under `/api/auth/*` and `/api/me`.
- Login, registration, and password-recovery web pages.

## Constraints
- Testcontainers and all container-based tests are cancelled by user instruction.
- No Docker Desktop or live database tests.
- Google OAuth requires configured credentials and is deferred until those are supplied.

- [x] Map Better Auth integration and environment boundaries.
- [x] Add Better Auth schema, migration, and Hono integration.
- [x] Create workspace-on-signup and session workspace resolution.
- [x] Add login, registration, and password-recovery UI pages.
- [x] Configure transactional delivery for verification and reset-password emails.
