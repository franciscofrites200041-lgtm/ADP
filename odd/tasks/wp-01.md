# WP-01: Local environment

## Goal
Provide a reproducible local development environment with PostgreSQL 18, Caddy, and minimal web, API, and worker applications.

## Decision
`/readyz` in WP-01 confirms API readiness only. WP-02 will extend it with a PostgreSQL readiness check.

## Scope
- `infra/compose.dev.yaml` and `infra/Caddyfile`
- Minimal `apps/web`, `apps/api`, and `apps/worker` shells
- API `GET /healthz` and `GET /readyz` endpoints with tests
- Root development orchestration through pnpm and Turborepo

## Out of scope
- Database schema, migrations, and database readiness checks (WP-02).
- Authentication, business endpoints, UI flows, and production deployment.
